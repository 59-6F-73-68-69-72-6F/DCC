Light Link Savior

Save and restore the light linking state of your scene lights — version 1.0.0

1. What it does

Light Link Savior captures which objects and collections each light illuminates (receiver links) and which ones it shadows (blocker links), and saves that state to a temporary file. Later you can restore that exact setup with one click.

Useful when lights are being reshuffled, re-parented, or when a shot needs the same linking layout reapplied after heavy edits.

2. Requirements

  • Blender 4.0 or newer (Light Linking must be available).
  • Write permission on the addon folder (to store the temporary stash file).

3. Installation

Step 1 — Copy the light_link_savior folder into Blender’s addons directory (e.g. scripts/addons/).
Step 2 — Open Edit > Preferences > Add-ons.
Step 3 — Search for “Light Link Savior” and tick the checkbox to enable it.
Step 4 — In the 3D Viewport, press N to open the sidebar and go to the Lighting tab. The Light Link Savior panel is there.

4. How to use it

Set up your light linking as usual (receivers / blockers via Blender’s Light Linking panel).

Save

In the LIGHT LINK SAVIOR panel click Save.
The current receiver and blocker state of every light in the active scene is written to a JSON stash file.

Restore

Click Restore. The previously saved state is re-applied to the scene lights. Once restored, the stash file is deleted — the recovery is a one-shot operation.
If you click Restore before ever saving, Blender reports “No saved light links to restore”.

5. What is saved

LightCaptured data
Receiver linksCollections and objects that receive light, with their INCLUDE / EXCLUDE state.
Blocker linksCollections and objects that cast shadows for the light, with their INCLUDE / EXCLUDE state.

Requirements are matched by name. Objects and collections must still exist (and keep their names) when restoring.

6. Where the data is stored

The state is saved as a temporary JSON file at:

<addon folder>/temp/light_linking_stash.json

The file is overwritten on Save and removed after Restore.

7. Troubleshooting

SymptomFix
“No saved light links to restore” Run Save first. The stash was consumed by a previous Restore.
Some objects are not restored The object/collection was renamed or deleted since the Save. Rename it back to relink.
Can’t enable the addon Check you are using Blender 4.0+, the correct addons folder, and that the addon is the complete light_link_savior package.
Save/Restore does nothing that you can see Make sure you have at least one light object whose light linking you can modify (panel may appear elsewhere in Layout too).

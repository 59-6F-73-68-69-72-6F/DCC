1. Introduction

The Layer Manager is a Blender add-on built for render-artist workflows. It gives you a single, readable table of all your collections and their per-view-layer render flags — EXCLUDE, HOLDOUT, and INDIRECT — right in the 3D Viewport sidebar.

Instead of scattering toggles across dozens of view layers in the Outliner, you see everything at a glance, stage changes safely, and commit them in one click. You can even copy one view layer's complete setup to all the others.

2. Installation

Requirements

  • Blender 5.0 or newer.
  • The add-on ships as a folder (version.1.1).

Steps

  1. Open Blender.
  2. Go to Edit › Preferences › Add-ons.
  3. Click Install… and select the __init__.py file or the add-on folder inside version.1.1.
  4. Enable the add-on by ticking Interface › Add-ons › Lighting › Layer Manager.
  5. Find the panel at View 3D › Sidebar (N-key) › Layer Manager.

Update

  1. Disable the old version in Preferences › Add-ons.
  2. Remove the old add-on folder from your scripts directory if needed.
  3. Install the new version and re-enable it.
Duplicate add-on detected? If the panel says “Layer Manager is not registered”, you probably have two copies enabled. Disable one and re-enable the other.

3. Quick Start

  1. Open the Sidebar in the 3D Viewport with N and click the Layer Manager tab.
  2. Choose the view layer you want to edit from the view layer selector at the top.
  3. Click any flag cell to stage a change (it toggles visually).
  4. Press OK to commit, or CANCEL to discard.

That's it — you're already managing layers from one place.

4. The Panel Interface

The panel is organized in four areas.

4.1 Tool row

  • View layer selector — the dropdown that switches which view layer's flags the table shows.
  • Refresh button (↻) — forces Blender to re-read the live state of all view layers.

4.2 The table

Each row is a collection. Column order:

  • Collection name — indented by depth; row name follows a disclosure triangle (▸ expandable / ▾ expandable-and-open). Leaf collections have no triangle.
  • Three flag cells — one per render flag. A filled icon means the flag is on, an outline icon means off.

4.3 Pending bar

Shows Pending changes: N and the OK / CANCEL buttons. The buttons are disabled until at least one change is staged.

4.4 Override row

A dedicated row for copying the current view layer's flags to every other view layer (see §6). Requires two or more view layers.

5. The Staging Workflow

The panel uses a stage ▶ apply workflow: nothing actually changes in your scene until you confirm it.

  1. Click a flag cell to stage the opposite of its current state. The icon updates immediately, and the pending counter increments.
  2. Click again to unstage the change — the counter returns.
  3. Click a parent's flag and the same state is staged for every child collection below it, saving you many clicks.
  4. Press OK to write all staged changes at once, or CANCEL to throw them all away.
Multiple view layers. You can stage changes for several view layers in one sitting — switch the selector, make your changes, switch again — and apply them all together with a single OK.
Delete a collection while changes are staged? The add-on is resilient: it re-checks the live scene before applying and simply skips collections it can no longer find, so leftover staging never causes errors.

6. Copy (Override)

The Override button takes the view layer currently selected in the table and copies its entire flag setup onto every other view layer — immediately.

  • It applies instantly (no staging).
  • Only flags that actually differ are written.
  • Any changes you had staged are discarded, because the override supersedes them.
  • A message reports how many flags were written.
  • The button is disabled when there is only one view layer.

7. The Flag Reference

What the three flags mean in Blender rendering:

Flag Blender property Effect
EXCLUDE Layer Collection → Exclude The collection is excluded from the view layer: it is not visible, not rendered, and not ray-traced against.
HOLDOUT Layer Collection → Holdout The collection renders as a holdout: objects are hidden in the final image and cut a hole in everything behind them. Useful for mask/composite passes.
INDIRECT Layer Collection → Indirect Only The collection only contributes indirect light (bounces); it is invisible in the beauty pass but still affects lighting elsewhere.
These are the exact same settings you can flip manually in the Outliner (View Layers) — the add-on just makes them visible in one place for all view layers at once.

8. Pro Tips

  • Naming matters. The table lists collections by name. Clear names make the table far more readable.
  • Stage, then verify. Watch the pending counter and the visual icon changes before pressing OK — nothing is written until you do.
  • Override for light rigs. When every view layer needs the same light rig settings, override once and then tweak per layer.
  • Use Indirect for global light blockers such as studio bounce objects, without polluting the beauty pass.
  • Refresh after heavy edits. If you've been restructuring collections in the Outliner, hit the refresh button to re-sync the table.

9. FAQ & Troubleshooting

Why do my changes disappear?

If you press CANCEL, everything staged is discarded — that's the expected behaviour. OK is what commits them.

Why does the panel say "No view layers"?

The current scene has no view layers. Blender scenes can be stripped of view layers; add one back in the View Layer dropdown of the 3D Viewport header.

Why is the Override button greyed out?

You need at least two view layers in the scene. With one view layer there is nowhere to copy to.

"Layer Manager is not registered" message

You have a duplicate copy of the add-on enabled. Disable every instance in Preferences › Add-ons and enable only one.

A collection I staged isn't applied

The add-on skips collections it can no longer resolve (deleted, renamed, or removed from that view layer). Restage after fixing the collection in the Outliner.

Will this touch my actual collection visibility?

No. The add-on only touches the three render flags (EXCLUDE / HOLDOUT / INDIRECT) on view layer collections. Collection viewport/runtime visibility is unaffected.

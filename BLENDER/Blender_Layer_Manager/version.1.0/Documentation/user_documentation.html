Blender Layer Manager v1.0 — User Documentation

Overview

The Blender Layer Manager is a native Blender add-on for managing collection visibility across view layers from a single panel. It gives you per-view-layer control of the three layer flags — Exclude, Holdout, and Indirect Only — with a clear table layout, one column per view layer, and one click per flag.

AuthorRudy Leti
Version1.0.0

Installation

  1. Copy the layer_manager folder into Blender's scripts/addons/ directory (or zip it and use Install…).
  2. In Blender, go to Edit → Preferences → Add-ons.
  3. Search for "Layer Manager" in the add-on list and enable it.
  4. The panel appears in the 3D View → Sidebar → Layer Manager tab.
Note: Press N in the 3D View to toggle the sidebar if it is hidden.

Interface Overview

1. Header Row

The header shows the Refresh button (top-right), a COLLECTIONS column, and one column per view layer (labelled with the render-layers icon).

2. Collection Rows

Each collection is one row. Deeper collections are indented to reflect the Outliner hierarchy. Rows with children show a disclosure triangle to expand or collapse the nested collections.

3. Flag Cells

Each row has one cell per view layer containing the three flag toggles for that collection:

FlagIconDescription
ExcludeCheckboxExcludes the collection from the view layer (objects stop contributing to viewport and render).
HoldoutMaskMasks the collection out of the final render, like a hole in the image.
Indirect OnlyDotRenders only the indirect (bounced) light contributions of the collection.

4. Action Bar & Footer

A "Pending changes: N" counter shows how many flag changes are staged. The OK and CANCEL buttons apply or discard the staged changes. The footer displays the copyright notice.

How to Use

Expand / Collapse

Click the disclosure triangle next to a collection name to show or hide its children. Nested collections are indented proportionally, matching the Outliner's hierarchy.

Toggle a Flag

Click any flag icon in a collection's row to toggle that flag for the current state. When you toggle a parent collection, the same change is also staged for all of its descendants, so you can exclude an entire branch with a single click.

Staging vs. Applying

  • Toggles are staged first — nothing is written to the scene until you press OK.
  • Press OK to commit all staged changes to the view layers.
  • Press CANCEL to discard all staged changes and restore the previous state.
  • The action buttons are enabled only when at least one change is pending.
Note: While changes are pending, the panel shows the effective state (staged changes overlaid on the current scene state), so you can preview the result before applying.

Keep the Panel In Sync

The panel auto-refreshes when the scene changes (Outliner edits, undo/redo, file load). If the displayed state ever looks out of date, click the Refresh button in the top-right corner of the header to force a full rebuild.

Tips

  • Batch exclusion: Toggle a parent collection to stage the same flag for its whole branch — ideal for excluding large asset groups from a view layer.
  • Preview before committing: Stage changes, check the "Pending changes" counter and the visual preview, then press OK.
  • Multi-view-layer workflow: Each column is an independent view layer, so the same collection can be visible in one render layer and excluded in another.
  • If in doubt, Refresh: Any external change to collections or view layers is picked up automatically; the Refresh button is a manual safety net.

Troubleshooting

IssueSolution
Panel not showingEnsure the add-on is enabled in Preferences. Press N to open the 3D View sidebar.
"Layer Manager is not registered."Disable any duplicate copy of the add-on, then re-enable it. Duplicate installations conflict.
Flag change has no visible effectPress OK — toggles are only staged until applied. Check that you are looking at the right view layer.
Panel shows a stale stateClick the Refresh button in the header (top-right) to rebuild the live state.
No view layers listedAdd a view layer in Properties → Scene → View Layers; the panel shows one column per view layer.
Missing collectionsOnly collections present in the scene root hierarchy are listed. Check the collection is linked to the scene and the row is expanded.

Uninstallation

Disable or remove the add-on via Edit → Preferences → Add-ons → search for "Layer Manager" → uncheck or remove.
